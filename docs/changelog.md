## 2026-07-24

### 三图缩放：新增滚轮／触控板捏合，按钮步进 1.5 → 1.3

行星图、群像图、舆地图此前只能按 ＋／－ 逐级缩放、滚轮无效。今于 `usePanZoom` 内加一路**以游标为锚的连续缩放**，三图共用。

- **走原生 non-passive 监听**，不用 JSX 的 `onWheel`：React 19 在根节点挂 `wheel` 为 passive，回调内 `preventDefault` 无效、页面照滚不误。故以 `wheelElRef` 取幅面元素，`addEventListener("wheel", …, { passive: false })` 自挂自卸。
- **1× 时不夺页面滚动**：静止时普通滚轮径直让位（`v.k === 1 && !e.ctrlKey` 即 return），划过图幅仍可翻页；唯触控板捏合（浏览器合成 `ctrlKey`）可于原始大小起手放大——同 Google 地图之例。已抵夹限者（`k2 === v.k`）亦不拦截，缩放到头自然接回页面滚动。
